AI Usage



AI assistance***(ChatGPT \& Claude)*** was used throughout the LoanTrack assignment as a development support tool.



1. Application development - Used AI to plan and implement the three-tier frontend, backend, and PostgreSQL architecture and API endpoints. 

2\. Database - Used AI to design the database schema, migration, seed data, connection  pooling, retry behavior, and health/readiness handling. 

3\. Docker - Used AI to create and review Dockerfiles, Docker Compose configuration, networking, healthchecks, volumes, non-root containers, and image optimization. 

4\. Kubernetes - Used AI to create and review Kubernetes Deployments, Services, PVC, ConfigMap, Secret configuration, probes, HPA, scaling, rolling updates, and rollback procedures. 

5\. Troubleshooting - Used AI to analyze Docker and Kubernetes errors, logs, pod behavior, database connectivity, and deployment issues. 

6\. Testing and verification - Used AI to plan verification commands and interpret the results from the actual Docker and Minikube environments. 

7\. Documentation - Used AI to prepare and organize the README, branching strategy, evidence documentation, and deployment instructions. 

8\. Git workflow - Used AI to help organize feature branches, commits, Pull Requests, tags, and the required Git workflow. 





How AI Suggestions Were Validated



AI was used as an assistance and guidance tool rather than as a replacement for testing. Commands, configurations, and implementation suggestions were applied to the actual LoanTrack environment and verified using Docker, PostgreSQL, Git, and Minikube.



When an issue appeared during implementation, the actual command output or application logs were used to investigate and make the required correction. The final repository reflects the configurations and changes that were successfully tested in the project environment.
